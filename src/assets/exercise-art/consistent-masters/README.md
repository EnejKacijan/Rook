# Consistent illustration masters

Catalog-wide replacement vectors from the local illustration consistency pass.
This directory contains 306 reviewed master SVGs accumulated across the approved
passes. The final full-library review covers 331 runtime artworks / 349 catalog
records: 123 retained and 208 redrawn in that final pass, with no pending cases.
Master count is cumulative; it is not the final-pass replacement count.
Do not edit the live copy independently. Run `node scripts/generate-rook-derived-art.mjs` to restore these approved masters after any source import.

Style and addition requirements: `docs/ILLUSTRATION-STYLE.md` and `docs/exercise-illustration-system.md`.
Subjects and generation constraints: `prompts.json` and `scripts/illustration-consistency-jobs.mjs`.
The existing 26 earlier movement/equipment corrections remain separately in `corrected-masters/`.

Original generated PNGs, exact pre-pass SVGs, full contact sheets, browser geometry checks, and before/after samples are in the local `artifacts/ROOK-BASELINE-CORRECTION-REVIEW/illustration-consistency/` package.

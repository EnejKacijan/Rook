Data access & deletion

Export your data, remove local data, or request a separate cloud/account deletion.

Draft — not ready for public release

Verified operator/contact details and the release checks must be completed before these notices become final.

Export and correction

Profile → Data & backup → Back up ROOK creates a recovery file of local data, with the photo options described in that screen. Export workout history offers CSV or JSON. You can edit profile details and correct supported workout history in the app. Handle exported files as private data.

Delete local data

Choose Profile → Data & backup → Delete local data, or the same action in Privacy & legal. Read the existing confirmation before continuing. It erases ROOK data from this device; this is not an account-deletion request. Signing out likewise leaves the cloud copy in place.

The operator cannot remotely erase backup files you exported or copies on other devices. Remove those copies separately if you want them deleted.

Request account/cloud deletion

Use the verified operator email on Operator & contact. From Privacy & legal, Request cloud data deletion prepares an email draft when that address is configured. You still need to send it; opening a draft does not submit a request.

Identify the account sign-in email and say you want the account and associated training/cloud data deleted. Never include your password, payment credentials, photo collection or a full backup. Reasonable identity verification may be needed before deleting account data.

The operator must acknowledge and handle the request under the applicable legal deadlines, explain any lawful exceptions, remove account-linked cloud records and authentication identity, address service-provider copies and confirm the outcome. Local deletion alone does not perform those steps.

Release status

The verified operator contact and cloud/account deletion runbook must be completed before public release. This draft page is not an automated deletion endpoint and does not claim that a request has been submitted or fulfilled.
